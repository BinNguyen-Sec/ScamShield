# Roadmap

This roadmap is provisional and will be updated as research and testing produce evidence.

## Phase 0 — Research & Discovery
**Status: In progress**

- [ ] Pilot and distribute the user survey.
- [ ] Analyze responses without overstating representativeness.
- [ ] Interview selected users and, where possible, cybersecurity practitioners.
- [ ] Document Vietnam's online scam landscape and public initiatives.
- [ ] Compare existing user-facing protection tools.
- [ ] Evaluate threat-intelligence sources, licensing, freshness, and coverage.
- [ ] Record browser extension API constraints and privacy implications.

## Phase 1 — Requirements and Design
**Status: Planned**

- [ ] Define use cases and abuse cases.
- [ ] Create a threat model and privacy review.
- [ ] Define indicator schema and verification states.
- [ ] Define measurable prototype acceptance criteria.
- [ ] Confirm a feasible, sustainable architecture.

## Phase 2 — Threat Intelligence Prototype
**Status: Planned**

- [ ] Implement source adapters for permitted feeds.
- [ ] Normalize and deduplicate URL/domain indicators.
- [ ] Add evidence, confidence, status, and lifecycle metadata.
- [ ] Generate a versioned feed with integrity verification.
- [ ] Add tests and source attribution.

## Phase 3 — Browser Prototype
**Status: Planned**

- [ ] Build a minimal Chrome/Edge extension.
- [ ] Evaluate URL matching and redirect behavior.
- [ ] Implement clear warning and allow/continue UX.
- [ ] Test local data updates and offline behavior.
- [ ] Review permissions and performance.

## Phase 4 — Evaluation
**Status: Planned**

- [ ] Build a documented test corpus.
- [ ] Measure false positives and false negatives.
- [ ] Conduct usability tests.
- [ ] Review privacy and security assumptions.
- [ ] Publish limitations and next steps.
