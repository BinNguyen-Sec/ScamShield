# Competitor Analysis

Document relevant tools and services using consistent, evidence-based criteria.

## Comparison Criteria

- Supported platforms and coverage.
- Types of threats detected.
- Data sources and update frequency.
- Warning experience and explainability.
- Privacy policy and permissions.
- Offline behavior.
- Reporting and correction mechanisms.
- Pricing, availability, and limitations.

Distinguish vendor claims from independently verified behavior. Include source links and the date each product was reviewed.
