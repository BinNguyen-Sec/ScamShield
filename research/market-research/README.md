# Market Research

Use this directory to document Vietnam's online scam landscape, public statistics, government initiatives, and relevant industry developments.

## Suggested Evidence Register

| Field | Description |
|---|---|
| Claim | The exact claim being supported |
| Publisher | Organization or publication |
| Publication date | Date released |
| Source | Direct URL or document reference |
| Scope | Geography, population, and period |
| Method | Survey, police report, administrative data, estimate, etc. |
| Caveats | Definitions, sampling limits, and uncertainty |
| Accessed | Date the source was reviewed |

Keep survey estimates separate from reported crime figures and financial-loss estimates. Explain differences in definitions and methodology before comparing numbers.
