# Threat Intelligence Data Sources

This document tracks candidate sources for potential ScamShield integration. Listing a source does not imply that it has been approved or integrated.

## Evaluation Checklist

For each source, record:

- Publisher and official documentation URL.
- Data format and access method.
- Threat categories and geographic coverage.
- Update frequency and indicator freshness.
- Confidence, verification, and false-positive handling.
- Licensing, attribution, and redistribution conditions.
- API keys, rate limits, quotas, and acceptable-use policy.
- Retention and privacy implications.
- Operational reliability and maintenance requirements.
